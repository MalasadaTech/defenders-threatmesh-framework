# P0103.004 - DNS: SOA RName

**As a** cyber threat intelligence analyst  
**I want** to identify unique or non-generic SOA RName values on a domain  
**So that** I can use them as reliable pivots to find additional adversary infrastructure.

## Acceptance Criteria
- System extracts the SOA RName field from DNS records (via VirusTotal or direct query)
- Filters out common/generic values (e.g. hostmaster, dns, admin, postmaster)
- Flags uncommon RName values as high-value pivots
- Presents the RName for easy searching in threat intelligence platforms

## Why This Pivot Matters
The SOA RName is the email address of the person or team responsible for the DNS zone. While often generic, a unique or personalized value is a strong OPSEC indicator and excellent pivot because it can link multiple domains to the same operator.
