# P0101.003 - Registration: Registrant

**As a** cyber threat intelligence analyst  
**I want** to identify exposed registrant names on a malicious domain  
**So that** I can find additional domains registered by the same person or organization.

## Acceptance Criteria
- System checks RDAP/Whois data for the registrant name field
- Flags names that are not privacy-protected or appear unique/non-generic
- Presents the registrant name as a high-value pivot

## Why This Pivot Matters
Most modern domain registrations hide registrant details with privacy services. An exposed registrant name is a significant OPSEC failure and a strong pivot for clustering adversary infrastructure.
